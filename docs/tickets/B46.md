### How the checks decide

| Result | What happens (Build Scope 28.2 step 6) |
| --- | --- |
| Every check passes | Published automatically within minutes; buyer gets the live link |
| Any hard fail (banned topic, more than 2 links, money word in link text, under 450 or over 2,000 words, script or form in the HTML, unsafe or previously rejected link, copied text, 2 refusals in 12 months) | Full Stripe refund automatically, reason emailed, one free resubmission |
| Otherwise borderline (one ambiguous term, 450–599 or 1,501–2,000 words, link text over 5 words, link to a site that isn't the buyer's, a link not responding, partial originality match, off-topic for the category, no subheading, small image, 1 earlier refusal) | Owner's queue, decided within 3 working days |

Until link safety has been checked after payment, a post is never auto-published. (The originality check is off by owner decision; see Decisions.) The page shows the same checks while the buyer writes, so most problems are fixed before anyone pays.

### Enquiry classifier rules (step 2)

Auto-reply when the subject or body contains any of: sponsored post, guest post, guest article, link insertion, write for us, collaboration, backlink, do-follow, dofollow, article placement, price per post, publish my article, paid post. Unsorted queue when only "collaboration" or "partnership" matches with no other term. Never auto-reply to: an address that is a TD member or customer, a reply to an earlier TD email, a support or billing thread, or the same sender within 30 days.

## Search and AI search (added 30 October 2026)

What the buyer gives us on the order page, and what the published post carries:

| Item | Order page | Published post |
| --- | --- | --- |
| Search summary (meta description) | Box with a counter, 70–160 characters. Left empty, the first paragraph is used and shown as a preview | `<meta name="description">`, Open Graph and structured-data description |
| Tags | Up to 5, comma-separated, 30 characters each, at least 1 needed. Checked against banned topics like the article | `article:tag`, structured-data `keywords` and a visible "Topics" line |
| Title | Over 70 characters is a borderline flag (Google cuts it off) | `<title>Title \| Sponsored \| TechDirectory</title>` and `headline` |
| AI answers | Tip: use question-style subheadings ("How long does a migration take?") answered in the first sentence below | Whole article in the HTML, no script needed; visible published and "Last updated" dates |
| Labelling | – | "Sponsored" badge above the title, "Sponsored by {company}", disclosure line, `sponsor` in structured data, every link `rel="sponsored"` |
| Discovery | – | Canonical URL, `index, follow, max-image-preview:large`, breadcrumbs, sitemap entry and an IndexNow ping on publish (B59) |

There is no `<meta name="keywords">` tag on purpose: Google ignores it and Bing reads it as a spam signal. Tags do that job instead.

## Order flow after the form: built (30 October 2026)

**Decided: a free Cloudflare Worker** (`automations/cloudflare/b46-orders/`). Cloudflare's free plan is already in the approved Year 1 stack (Build Scope 23), Make Free can't run the checks, and it costs nothing. Tests: `cd automations/cloudflare/b46-orders && npm install && npm test`, **41 of 41**.

| Step | What the Worker does |
| --- | --- |
| Order form sent | Checks again on the server (the browser can't be trusted). Hard fails, a paused switch or a full week stop it **before** anyone pays. The image size is read from the file itself |
| Payment | Stripe Checkout in USD, GBP or EUR; the place is held for 35 minutes and freed if checkout is abandoned |
| After payment | Each link: does it respond, is it safe (Google Web Risk), was it rejected before; the buyer's refusal history (the Copyscape originality check is built but switched off) |
| Every check passes | Published through the TD API with the Sponsored label, `rel="sponsored"` links, structured data, search summary and tags; IndexNow ping; buyer emailed the link |
| Hard fail | Full Stripe refund, reason emailed with one free resubmission, unsafe link domains remembered |
| Borderline, or anything goes wrong | Owner's queue; **never published or refunded automatically**. Owner publishes or refunds with one call |

Safety rules it keeps: Stripe signatures checked and replays older than 5 minutes refused; each payment acted on once; nothing is ever treated as safe if a check service is missing or fails; the CPU cost per post is about 2–3 ms, inside the free plan's 10 ms.

What it needs at go-live (owner, about 20 minutes, keys go into Cloudflare's secret settings, never GitHub):
- A Cloudflare account (free) — the same question as B59.
- Google Web Risk key: free up to 100,000 checks a month (we will use about 60).
- Google Web Risk needs a Google Cloud project with billing switched on (a card on file). At our volume it costs nothing; a £1 budget alert is set so any charge is flagged.
- Brevo API key for the buyer emails (transactional only; no lists, campaigns or templates are touched). Until it is added, emails wait in an outbox and nothing is lost.
- TD API key, and the post-type and author IDs (I read these in the admin in the window).
