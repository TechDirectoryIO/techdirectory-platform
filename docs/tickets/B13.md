## How it works

- **One settings block** at the top of the widget: switch, link, button text, heading, description, the two prices, referral code, end date and which placements show. Nothing else holds a copy of the link, text or prices.
- Each placement is an empty slot plus the widget shortcode: `<div data-td-tb="panel|strip|line" data-placement="…"></div>` then `[widget=TD TechBullion Link v1]`.
- Links open https://techbullion.com/media-kit in a new tab with `utm_source=techdirectory&utm_medium={placement}&utm_campaign=publishing`, `rel="sponsored noopener"` and an accessible "opens TechBullion.com" label. Panels carry `data-nosnippet`.
- At most one TechBullion panel or strip per page. The footer "Publishing" link hides itself when the switch is off.
- Click event `td_publishing_click` with the placement name goes to GA4 only where analytics is loaded (after cookie consent once B05 is live).
- Brand colours are inline (Build Scope 19: until T04 loads the brand stylesheet); Manrope falls back to Arial until T04 uploads the font.

2. Optional, full removal: delete the footer menu item; switch the dashboard back to the original widget; set /publishing to hidden (301 it to `/` if it has been indexed); disable the widget.
3. Run the 12-point smoke test. Nothing else refers to TechBullion.
